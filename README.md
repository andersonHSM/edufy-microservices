# Projeto de Microserviços

## Sobre

Este é um projeto desenvolvido durante um curso de microserviços, utilizando TypeScript e tecnologias modernas para
desenvolvimento de software distribuído.

## Tecnologias

- TypeScript 5.9.2
- Turbo 2.5.8
- Prettier 3.6.2
- pnpm (Gerenciador de pacotes)
- Docker
- Kubernetes
- RabbitMQ
- Redis

## Arquitetura

O projeto é composto por diversos microserviços independentes que se comunicam através de mensageria e APIs REST.

## Requisitos

- Node.js (versão LTS recomendada)
- pnpm instalado globalmente
- Docker
- Kubernetes CLI (kubectl)
