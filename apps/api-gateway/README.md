# API Gateway - Edufy Microservices

API Gateway que serve como ponto de entrada único para todos os microserviços do Edufy.

## Funcionalidades

- ✅ Roteamento para Auth API (port 3001)
- ✅ Roteamento para Users API (port 3002)
- ✅ Validação de JWT
- ✅ Rate limiting e throttling
- ✅ Health checks dos serviços
- ✅ Cache com Redis
- ✅ CORS configurado
- ✅ Logs estruturados
